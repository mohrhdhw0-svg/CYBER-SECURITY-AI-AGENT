# CYBER SECURITY AI AGENT

منصة دفاعية موحدة لإدارة المختبرات الأمنية، تنظيم أدوات الفحص، تحليل النتائج، وإعداد التقارير.

## الحالة الحالية
هذه هي النواة الأولى للواجهة. لا يتم تشغيل أي أداة هجومية من المتصفح مباشرة. تكاملات الأدوات ستضاف عبر عمال تنفيذ معزولين، وبنطاقات مصرح بها فقط.

## المتطلبات
- Node.js 20.9+
- npm

## التشغيل
```bash
npm install
npm run dev
```

## متغيرات البيئة
انسخ `.env.example` إلى `.env.local` وأضف مفاتيح الخدمات عند إعداد التكاملات. لا تضع الأسرار في المستودع.

## محرك التنفيذ الأولي
يوجد محرك Docker منفصل في `engine/` مع موصل Nmap محدود. المحرك لا يعمل داخل Vercel؛ يجب تشغيله على خادم خاص أو مختبر محلي، وضبط `ENGINE_API_TOKEN` و`AUTHORIZED_CIDRS` وفق نطاق تملكه أو لديك تصريح مكتوب لاختباره. راجع `engine/README.md`. لا تعتبر بقية عناصر الكتالوج جاهزة للتشغيل حتى يضاف موصلها ويجتاز اختبارات التكامل.

## خارطة الطريق
1. واجهة لوحة التحكم والكتالوج.
2. المصادقة والأدوار وسجل التدقيق.
3. إدارة الأصول والنطاقات المصرح بها.
4. API للمهام وطابور Redis.
5. عمال Docker معزولون للأدوات.
6. تحليل النتائج والتقارير.
7. تكامل AI Agent مع موافقات بشرية للعمليات الحساسة.

## ضوابط السلامة
- لا فحص إلا لأصول يملك المستخدم تصريحاً مكتوباً لاختبارها.
- التحقق من النطاق المسموح قبل إنشاء أي مهمة.
- حدود للسرعة والوقت والموارد.
- حفظ سجل تدقيق لكل عملية.
- عدم تنفيذ استغلال أو تخمين كلمات مرور على أنظمة عامة.
